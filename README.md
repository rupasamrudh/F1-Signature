# F1 2026 Racing Simulator 🏎️

A Formula 1-inspired racing simulation game built using **Unity 6**. The project aims to deliver an immersive racing experience with realistic vehicle physics, 3D Formula racing cars, and dynamic driving mechanics.

## 🚀 About the Project

This project is an attempt to develop an F1 2026 racing simulator that captures the excitement of Formula racing through realistic car movement, steering, acceleration, braking, and an immersive driving experience.

The game is currently under development, with new features and improvements being added progressively.

## 🛠️ Built With

- **Unity 6** – Game development engine
- **C#** – Gameplay programming and vehicle systems
- **3D Models** – Racing car models and track environments

## 🎯 Project Goals

- Develop realistic Formula racing vehicle physics.
- Implement responsive steering, acceleration, and braking.
- Integrate detailed 3D Formula racing cars.
- Create immersive engine and racing sound effects.
- Build engaging racing tracks and environments.
- Continuously improve gameplay, visuals, and performance.
